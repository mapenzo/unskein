## Decided
- El público son equipos con monolito que quieren desacoplar, pero la función de contextos aún no existe. El lema tiene dos tiempos: uno honesto para hoy y otro que solo se publica tras validarlo.
- In the code: README y lema: usar el texto provisional de `docs/decisions/0003-lema-provisional-literal.md`. El lema de `[contexts]` solo entra cuando exista el caso con tests en un proyecto público (ADR 0001).
